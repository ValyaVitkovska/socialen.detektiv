СОЦИАЛЕН ДЕТЕКТИВ – PWA

Файлове:
- index.html – играта
- manifest.webmanifest – настройки за инсталиране
- sw.js – офлайн режим
- icon-192.png / icon-512.png / apple-touch-icon.png – икони на приложението
- geo.png – Гео
- logo.png – авторско лого

ВАЖНО: За да работи бутонът „Инсталирай приложението“, качете ВСИЧКИ файлове заедно в една папка в GitHub Pages (или друг HTTPS хостинг). Отворен само като локален HTML файл, браузърът не може да инсталира PWA.
